# Urban Pluvial Flood Risk — Exploratory Data Analysis

## 📌 Project Overview

This project presents an **Explanatory Data Analysis (EDA) pipeline for Urban Pluvial Flood Risk**. The analysis explores geographic, environmental, rainfall, elevation, and drainage-related factors to understand patterns associated with urban flood risk.

## 🎯 Business Context

Urban flooding can disrupt infrastructure, damage property, and affect city economies. This analysis aims to support **city planners, policymakers, infrastructure agencies, researchers, and insurers** in identifying vulnerable areas and supporting data-driven flood mitigation and climate-resilience planning.

## 📊 Dataset

The project uses the **Urban Pluvial Flood Risk Dataset** available on Kaggle:

[Kaggle Dataset](https://www.kaggle.com/datasets/emanfatima2025/flood-disaster-data)

The dataset contains information including location, elevation, land use, soil group, drainage density, storm-drain proximity, rainfall intensity, return periods, and flood-risk labels.

## 🔍 Analysis Performed

* Data loading and initial exploration
* Data quality and preprocessing
* Spatial flood-risk analysis
* Elevation and drainage analysis
* Historical rainfall analysis
* Correlation analysis
* Feature relationship analysis
* Risk-category comparisons
* Data-driven insights and recommendations
